## Downloader for onlyfans.com

The Chrome extension adds download buttons to supported OnlyFans posts and galleries. Sign in directly on OnlyFans and use the extension for content you have permission to download.

## 🚀 Installation

### Manual Installation

1. [Download the Chrome extension ZIP](https://hlsdownloader.com/how-to-install-onlyfans-downloader-from-a-zip-file) and extract it to a folder.
2. Open `chrome://extensions/` and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder containing `manifest.json`.

See the [illustrated installation guide](https://hlsdownloader.com/how-to-install-onlyfans-downloader-from-a-zip-file) or [verify the ZIP checksum](https://hlsdownloader.com/guide/verify-installer) before installing.

### Web Store

The Chrome extension is currently distributed as a ZIP for manual installation.

## 🤔 FAQ

**What can I download with the extension?**  
You can save supported videos and photos from OnlyFans posts you can access and have permission to download. Protected streams have limited support.

**Why won't Chrome load the extension?**  
Extract the ZIP first. In **Load unpacked**, select the folder that directly contains `manifest.json`.
